# Stillmere model credits

Every file in `public/models/` is CC0. Textures are packed into the glTF, meshopt-compressed, with a 512px atlas (256px on the far level).

The player is not one of these files. The Gobkit Rat (CC0, [Animal Pack Vol. 2](https://gobkit.itch.io/gobkit-free-animal-pack-vol-2)) still reads as a rat: long tail, snout, and a mouth bone. The mouse you walk is built in code instead: warm brown, a bigger head, round ears, a short tail, about 0.4 m tall.
